# find_lines

A small search tool.

## Usage

```
usage: find_lines [-h] [--ignore-case] pattern file

Print the lines of FILE that contain PATTERN.

positional arguments:
  pattern        the text to look for
  file           the file to search

options:
  -h, --help     show this help message and exit
  --ignore-case  match without regard to case
```
