# INC-009: login degraded

**Team:** payments  
**Duration:** 200 minutes  
**Severity:** SEV-3

## Summary
login returned errors for 200 minutes; customers saw failed requests.

## Timeline
- 00:00 alert fired
- 00:09 on-call engaged
- 03:20 resolved

## What happened
Investigation showed that a memory leak in the login cache client grew until the kernel's OOM killer stopped the process.

## Contributing factors
- a deploy freeze was in place, which slowed the fix

## Follow-ups
- add an alert for this condition
- update the runbook
