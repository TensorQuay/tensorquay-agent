# Releases, 2025-03

## 4.2.0

- Reduced memory use of `export` by 30 %.
- Added `tq status --json`.
- `--verbose` is deprecated in favour of `--log-level debug`; it still works.
- The config key `server.port` is renamed to `listen.port`; the old name is no longer read. Migration: rename the key to `listen.port`.
