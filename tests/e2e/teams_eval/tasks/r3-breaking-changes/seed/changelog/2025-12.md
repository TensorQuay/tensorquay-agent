# Releases, 2025-12

## 5.1.0

- Documentation: new tutorial on plugins.
- Removed the `cache.dir` config key. Migration: use `cache.path`.
- `tq doctor --fix` is deprecated; it keeps working until 6.0.
- Faster startup on large projects.

## 5.2.0

- The `q=` parameter of `/v2/search` is deprecated in favour of `query=`; both work.
- `Client(retries=...)` is removed. Migration: pass a `RetryPolicy`.
- Fixed a crash when the config file is empty.
- Added `tq status --json`.

## 5.3.0

- BREAKING: `report --html` is removed. Migration: use `report --format html`.
- Fixed a race in the sync lock.
- Fixed a crash when the config file is empty.
