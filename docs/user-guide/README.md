# TensorQuay Agent: user guide

TensorQuay Agent runs an agent for you in an isolated environment, for research, data, writing, operations or code.
You describe a task, the agent works on it in a workspace of files, and it reaches only the internet sites your
administrator allows. This guide describes the web app as it is today. Labels in **bold** are the words on the screen.

| Page | Content |
|---|---|
| [Tasks](tasks.md) | Start a task, follow the agent's work, stop a run, change the model or the environment |
| [Files, changes and context](files-and-changes.md) | Attach files, browse the workspace, review what each run changed, and see what the agent loaded |
| [Workspaces](workspaces.md) | Keep, reuse, copy, rename and delete the files your tasks work on |
| [Keys for web services](keys.md) | Add a key for a service your tasks call, name it, replace or delete it, use shared keys, and read what a task says when it uses one |
| [Sharing](sharing.md) | Share a workspace with other people, and who can see what |
| [Channels](channels.md) | Work with other people and your tasks' agents in a shared log: post, propose, vote and take on to-dos |
| [The desktop](desktop.md) | Give a task a screen, watch the agent work on it, take over to sign in, replay its steps, and what is kept |
| [Helpers](helpers.md) | Ask a task to lead helpers for work that splits, follow them, step in, and stop them (when your administrator has turned helpers on) |

The app follows your browser's language; **Language** in the Account menu changes it. **Theme** in the same menu
chooses **System**, **Light** or **Dark**. The agent's own answers are
not translated. For settings that only an administrator can change, see the
[administrator's guide](../admin-guide/README.md).
