# Generated wire contracts

Generated by `corepack pnpm protocol:gen` from the shared JSON Schema and the gateway OpenAPI document.
`corepack pnpm protocol:check` compares both types and runtime schemas, including a hash of all schema constraints.
`key-shapes.json` is `crates/tqa-types/src/key_shapes.json` as it is: what makes a secret's name look like a key, for
`src/settings/key-shapes.ts` (SEC-033, WEB-U-303).
Do not edit the generated files. The transcript reducer must handle every generated event variant exhaustively.
